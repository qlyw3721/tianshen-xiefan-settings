== 世界与机构 ==
- 第17行：圣事部=梵特兰蒂冈教廷异端裁决所；拜占奥教廷称"教皇审判厅"；大陆"精神之父"是拜占奥教廷(第18行)。梵特兰蒂冈400年前从拜占奥分裂，扎根神圣帝国(第18行)。圣事部机构隶属梵特兰蒂冈，权力凌驾其余2院8部(第18行)。
- 梵特兰蒂冈标志=黄金三角架；异端裁决所三大巨擘构成黑暗三角形(第19行)。
- 黑暗三巨头：①"神圣长矛"列司盾(第20行)，原拜占奥教皇第二顺位继承人，活了近150年，教廷权势排名第2(第58行)；②帝国守夜人条顿祭司/条顿公爵，守夜者领袖，魔法和奥术巅峰强者，排名第3(第21、59行)；③"母羊"组织的母亲、绰号黑山羊女王的"海姬"，排名第4，实际年龄起码90岁以上，曾把拜占奥红衣大主教用黑炼金术炼成傀儡(第22、60-62行)。圣事部第4位"黑色牧首"即将诞生(第23行)=奥古斯丁。
- 圣事部三大组织：圣灵厅、守夜者、母羊(第48行)；裁决厅成员被守夜者嘲讽为"教袍贵族"(第28行)。母羊下设三支研究实验室之一"羊角"(第162行)，另有"羊眼"(破译法术图案)、"黑羊"总部(第344、519行)。
- COSMO(第31、48、124行)：古拉丁语译作帝国官方语言即"秩序"(第124行)，圣事部新机构，皇帝亲自开口让奥古斯丁成为首脑；人员不到10个(第48行)。奥古斯丁自称"梵特兰蒂冈教廷的第4席大执政官"(第984行)，圣事部原本只有三位大执政官巨头(第986行)。秩序被称"不被官方认可的地下机构"(第577行)、"理论上规格与圣事部三大组织持平但特殊权力更胜一筹"(第837行)。
- 教务院：第4席国务卿帕尔梅(改革派，第25行)、次席国务卿萨笛(教廷实权排名第7的枢机大臣，绰号"雷切尔之虎"，第45、54行)。红衣大主教盖穆(第44行)、老红衣大主教安尼塔(第24行)、枢主教本杰明伯顿(帝都教区，45岁，保守派少壮派，钻研圣徒《教诲》，第24行)。福音部埃尔大主教。比萨主教(圣约翰大教堂，曾受圣徒伊耶塔教导，第109-110行)。
- 圣约翰大教堂：皇家专属教堂，帝都朱批特城(亦写朱毗特城)，梵特兰蒂冈教廷核心；有百花廊(各大家族徽章集合，第103行)、爱德华三世礼拜堂、图书馆。修女夏洛特(白品牧师，16年整理典籍，第69行)。
- 圣乌尔班雕像(第196-201行)：爱德华三世礼拜堂顶端13米高天使雕塑，一半是大天使Gabriel、一半是堕落天使长Lucifer；右手握石制《教诲》，左手悬挂"泰坦屠夫"澳狄斯亲王的干枯脑袋(第201行)；帝国史上4位大异端/叛国者头颅曾挂左手，澳狄斯是第5位(第199-200行)。奥古斯丁说"本来那里还应该挂上我父亲的脑袋"(第202行)。已屹立500年(第198行)。
- 紫曜花：罗桐柴尔德家族象征(第186行)；"百花廊"大理石上的家族徽章。紫曜花也指扈从：阿瑞斯是"象征最后一瓣紫曜花的扈从"(第273行)。13幅巨大肖像油画(第487行，后文第70章"第十三幅肖像画")。
- 使徒扑克牌：第603行——帝国首席奥术家圣哲罗姆(活了140多岁)与朱毗特大帝一同成为"使徒扑克牌12张人头牌之一"，大陆四大王国之一的神圣帝国只有两人获此殊荣。第230行：朱毗特大帝"代替老牧首填补使徒扑克牌空缺"。
== 主角 奥古斯丁·罗桐柴尔德 ==
- 24岁(第282行"现在奥古斯丁才24岁")；原奥古斯丁伯爵，被皇帝剥夺爵位(第38、122行)，保留司祭身份(第122行)。帝国东部奥格斯歌城人；罗桐柴尔德家族延续12代(第38行"辉煌了12代")、另处说14代(第115行"延续14代的罗桐柴尔德家族死亡了")——存疑(两处数字不一)。父亲=诗人公爵(第33、479行)、2号叛国者(第669行)；母亲=公爵夫人，拥有三个古老姓氏(第688行)；老管家老丕平(服侍三任家主，第479行)。
- 教父=圣徒伊耶塔(红衣大主教，主动放弃牧首权杖，3年前死于脉代奥拉修道院，第29、113行；遗言"我的教子，那位奥格斯歌城的孩子，会走得比我更远"第140行)。伊耶塔有两名教子(第601行)：奥古斯丁与拿破仑。拿破仑=帝国最年轻大司祭、老牧首教子、教廷双子星之一，肩膀蹲小白猫(第72、674行)，教廷官方正统标志、"火炬"教师(第901行)。
- 脉代奥拉修道院(空中修道院，离上帝最近)苦修3年(第38、119行)，结识庞培家族尼禄少爷、院长弟子约克，后决裂(第40行)。3年前走出修道院后秘密进入守夜者，两年4次破格提拔(第38行)，曾在守夜者潜伏(第282行)、爬升到第3号位置(第356行)。半年前亲手埋葬罗桐柴尔德(第38行)，是揭发家族叛国的告密者(第32行)，亲眼见证父亲上绞架(第38行)。
- 性格：表面和煦温和、虔诚安详、贫寒白袍祭司(第80-88行)；内里狡猾伪善、老牌贵族作派、吝啬、冷酷、"平静的疯子"(第297行)、"与整个世界作战的疯子"(第180行)、"帝国和教廷培育出来的怪物"(第248行)。口头信念："敌人不死，我就不会先倒下。这是教父给我的忠告"(第178行)；"与整个帝国为敌，累是累了点，可不会寂寞无聊啊"(第179行)；"罗桐柴尔德没有退缩者"(第300行)；"紫曜花永不凋零"(第500行，父亲上绞架前最后一句话，第501行)。
- 动机暗示：为何亲手送家族上绞架——全书多处暗示未明说。第113行比萨主教疑问"他为何要亲手染上家族的鲜血"；第128行"传言朱毗特大帝想借圣事部的暗黑之手让罗桐柴尔德最后的紫曜花花瓣消弭于尘埃"；第297行自述"父母也选择与家族一起走上断头台，那一刻，孩子才知道在这个世界，除了自己，他还有需要他去竭尽全力保护的东西"；第303-306行伊丽莎白问"你憎恨那个人吗"(端坐太阳之中、帝国最不容挑衅的角色=皇帝)，奥古斯丁答"我敬畏他"(未给真正答案)；第532行"等我到达黑天鹅湖，就意味着朱毗特大帝对我的庇护已经中止"。父亲遗言"敌人一天不死，紫曜花永不凋零"暗示家族自愿牺牲/有更大敌人。老丕平说"老爷和夫人始终以少爷为最大骄傲"(第495行)。存疑：真实动机可能是与皇帝的某种交易/替家族保留血脉/引出幕后仇家。
- 能力体系：①"思想点"：第54章标题，第269行"给我增加首席巨头列司盾制定出来的信仰点数"——信仰点数/功勋值(第598行"圣事部3大机构只讲究信仰点数即功勋值")，由列司盾制定，完成任务积累点数卡可进阶或兑换道具/金钱/女人(第740行)，奥古斯丁是"宗教裁决所50年来积累信仰点数最惊人进阶最迅猛的怪物之一"(第741行)。②等级：帝国主要职业阶层1-9级划分(第343行)；9级以上10-13阶高级骑士有1-3级巴思勋章；皇家2号骑士=圣骑士阶段16级；帝国6大骑士"圣棺骑士"约20级(第343行)。魔法师1-3低阶宿根草徽章、4-6中阶紫百合花、7-9高阶剑蝶菊、10-16郁金花(独瓣到6瓣)、17-20魔法贤者黄金三叶草勋章(第664-666行)。奥古斯丁24岁已考取9项以上主职能3级中的三分之二(第282行)，是"等级证书考核狂"；官方6级魔法师(第473行)、5级骑士认证(第378行)、5级魔法师(第665行)、核砝容量最多9级高阶(第964行)、核砝容量不如帝国任何一个5级魔法师(第547行)；理论超凡，被称"一头思想的巨龙"(第467行)、怪胎(第561行)。守夜者内部说法："宁肯给奥古斯丁一件咏叹级装备，也不要给他一个有充裕时间去支配的主场优势"(第561行)。③魔法阵/杠杆：擅魔法阵，提坦龙眼法杖(史诗级，巨龙眼珠来自最接近神祇的提坦龙族，第527-528行)，脉点/空间跳跃(第928行)。圣事部"净化""救赎"特权(第881、945、951行)：净化按就近原则、高级覆盖低级原则、领袖凌驾帝国法律三大原则(第894行)。
- 重要道具/法术：提坦龙眼法杖(第228、527行)；《摩羯思想书》(梵特兰蒂冈第2任牧首题字"向前走，向前看，向前想，肉体毁灭的那一天，就是我精神不朽的一刻"，第558行；伊耶塔字迹"上帝终将拯救那些动机纯正的义人"第559行；末页奥古斯丁写异端语"离天神最近的地方，就是离奥古斯丁最近的地方"第591行)；《阿约瀚歌13章》末尾"他独自从神圣中来，走向永恒的不朽"(第98行)；《佛伦蒂大教典》《教诲》《信仰之城》《帝国百科全书》《威廉首相回忆录——鲜血与鲜花/鲜花与鲜血》《魔法神圣体系》。
== 诗呢哥城堡 / 黑天鹅湖 / 上帝左眼 ==
- 黑天鹅庄园(玛索郡省西北角，茴香卑斯山脉下)，诗呢哥城堡=朱毗特大帝交给奥古斯丁的COSMO起点(第230-231行)。40多年前异端组织据点，由"黄金长矛"列司盾和条顿两大巨头指挥圣事部毁灭(第213行)。由大萨满"矮子奥贝"与lecch最高组织"犹大玛议会"某长老合作建成(第213行)。
- 地下迷宫9层：负1周长2439.61米=魔法术语"黄金的尾巴"基数(第255行)；负3真迷宫；负4植物园(约9000平米，太阳石镜面，"伊甸园"雏形，第315-317行)；星空大厅=黑天鹅湖底部(第288、581行)；第9层"上帝左眼"(第512行)：14块石碑围成圆(7块缪斯黑色符文+7块leech红色/高阶教士鲜血，含拜占奥两位红衣大主教与梵特兰蒂冈某位"圣子"之血)，圆心黑洞喷出核砝(介于气态液态)，14股解构成14种性质能量；共3重魔法阵：①14石碑+泉眼；②"献祭"大型死灵系禁术(49位萨满灵魂守卫立体防御)；③12黄道宫叠加魔法阵。由矮子奥贝用150年研究(第512行)。奥古斯丁计划"把诗呢哥底层的上帝左眼复制到整个黑天鹅湖"(第568行)，粗略版12黄道宫魔法阵(第571行)。
- "羊角"：海姬把母羊三支实验室之一羊角送给奥古斯丁(第161-162行)。到达时约70人，损耗率53%，幸存36名研究人员(第362行)；首席研究官腓伊(清秀古板、厚眼镜，第360行)；次席研究官雪莉教授(第436行)；理论大师小霍尔(5级魔法师，研究"第二暗金钟摆复合魔法阵"、100大魔法阵之一，第431行)；老骑士尤金(爱德华家族深蓝勋章，第430行)；班森(10级大剑士、橡树叶勋章，第422行)；29名护送成员(第396行)。红骷髅标志=禁区(第368行)。
== 超凡设定 ==
- 核砝：一切魔法和奥术的支点(第476行)；"核砝是一切魔法和奥术的支点，没有它，即使拥有最强大的杠杆，也撬不起魔法圆球"(第476行)。魔法师级数每升一级，可用魔法级数提高5级；20级皇家协会魔法师极限约80级魔法(第546行)。"50级+魔法""120级+【众神降临】几乎到达魔法顶峰的伟大技能"(第1005行)。
- 温泉：迅速补充使用魔法后枯竭核砝的法术液体，纯度越高补充效率越高；最高级"海洛罂"(书中亦写"海螺罂"，存疑：两种写法并存)，矿石最高等级"意志"(第610行)。"砝芽"级以上才被教皇店收购，95摄符以上(第683行)，99.99摄符(第685行)。"火神唾液/火神液体"=黄金体，喂养黄金傀儡、可制高阶魔法卷轴(第723、555行)。
- 黄金傀儡：傀儡系是炼金术重要环节；捕获黑暗深渊强大生物、灵魂坍缩成傀儡；越蛮横坍缩后体积越小；不是死物，需进食(第554行)。"上帝元素"十大中有7种与黄金同色(第555行)。暗金="上帝金属"序列，不能用金钱衡量(第433行)；暗金匕首能破解实体魔法元素构成、破除治疗(第844行)；"卢思镰刀"(第909行)。
- 伽马术=炼金术别称；"小伽马术"是不被正统认可的异端知识体系，与黑魔法并称"魔鬼左右手"(第595行)。爱尔兰亡灵书：主修者右手中指有暗金色纹理(与伽马皇帝交换契约)，辅修者小拇指一串暗金古拉丁符号(与伽马皇后签信仰合约)(第726行)。"咏叹"级装备(第546行)、"歌颂"级(第682行)、矿物评级"深秋"第5、"歌颂"第9、神圣/史诗/咏叹(第682行)。"亲魔法元素"道具可让元素魔法师发挥120%+~130%+(第557行)。审判者手套(红色，守夜者专用，第557、739行)。
- 魔法师等级徽章见上。骑士"信仰源泉"体系(第740、816行)：从爱情汲取能力者称"紫罗兰"骑士，成熟慢但离圣棺骑士更近(第816行)；帝国第六骑士古利格力=紫曜花最大扈从，曾挑战帝国首席骑士不败，刺杀皇帝失败后消失(第817-818行)。
- 帕雅战棋：第280行"我小时候最喜欢和一个死胖子玩战棋"、第912行"少年时代就喜欢跟他玩帕雅战棋的小胖子莱茵哈泰"。
- 暗金钟摆/第二暗金钟摆复合魔法阵：100大魔法阵之一(第431行)。玛雅神庙：魔法最高殿堂，124年前有个女人独自步入、创造同时制造每样元素各27颗的"神迹"(第877行)；圣唐纳德说迦卡妙"要么踏入玛雅神庙荣誉之地…要么毁掉我们精神支柱"(第901行)。
