## 二、逐字引语核验（核心表）

| # | 引语（逐字） | 行号 | 说话人 | 状态 | 备注 |

| 2 | | | | | |

> 状态说明：
> - ✅逐字＝与原文完全一致（含标点）；
> - ⚠️转述差异＝素材或记忆与原文有异（异体字／漏字／人称／润色），**以原文为准，差异单列留档**；
> - ❌误归＝说话人、对象或出处错了，必须当场修正认知。
