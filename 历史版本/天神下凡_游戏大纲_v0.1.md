# 《天神下凡》游戏大纲 v0.1

**文档性质**：主体框架 + 世界观补全（Game Design Outline，非完整 GDD）
**依据**：《天神下凡设定集.docx》全篇（354 段，约 1.7 万字）
**模板**：以《最终幻想》《勇者斗恶龙》《时空之轮》《最终幻想战略版》《女神异闻录》《八方旅人》《异度装甲》等经典日式 JRPG 的成熟结构为骨架
**版本**：v0.1 / 待拍板稿

---

## 0. 本版要解决的问题

设定集是一份**高质量的世界名词表**，但不是一份可用的游戏框架。它已经给出了别的项目很难有的东西：五大帝国与两大教廷的权力格局、四花色「使徒牌」这一极具辨识度的核心意象、八到九种主职业与「信仰源泉」这套近乎现成的成长系统、核砝／温泉／摄符／魔法级数这套近乎现成的资源数值、以及上百个可以直接做成图鉴条目的圣物、典籍、魔物与铠甲专名。

它缺的是四样把名词变成游戏的东西：

1. **主角与动机**：设定集提到「主角的父亲」罗桐柴尔德公爵被判叛国、绞死，遗言「敌人一天不死，紫曜花永不凋零」，但没有写主角自己要什么、故事从哪一天开始、到哪一天结束。
2. **一条能让玩家走完的旅程**：地名散落（白蔷薇、奥格斯歌城、玛雅雪山、黄金岛、光荣丘陵……），但没有动线、没有解锁节奏、没有章节。
3. **系统闭环**：职业、信仰源泉、阶位徽章、魔法级数、核砝、使徒牌各自成立，但彼此没有咬合关系。
4. **标题的落点**：「天神下凡」四个字在设定集里没有对应概念。最接近的是 120 级魔法【众神降临】、四方裁定使徒牌的玛雅神庙，以及那张始终空白的【皇后】人头牌。

本大纲的核心工作，就是**把第 4 点变成整个故事的引擎，同时用它把前 3 点串起来**。

## 1. 产品定位与一句话概念

### 1.1 Logline

> 神圣历 841 年，每二十年重排一次、被整个大陆当作神谕的「使徒牌」即将第 43 次改订。那张空了四十年的【皇后】牌，第一次出现了人选。
> 被教廷判为叛国者之子、连一张牌都没有的年轻奥术师，为了查清父亲被绞死的真相，被迫走遍四方裁定使徒牌的四大圣地——最后发现，**使徒牌从来不是神在选人，而是人在造神**。

### 1.2 定位表

| 项目 | 设定 |
| --- | --- |
| 类型 | 单机·剧情驱动·回合制 JRPG（群像叙事 + 职业养成 + 大地图巡礼） |
| 建议战斗制式 | ATB（最终幻想式实时蓄条）+ 前后排站位，非战棋 |
| 美术方向 | 2D-HD 多层景深（八方旅人式），便于承载高密度专名与插画式圣物 |
| 体量 | 主线 45–55 小时，全要素 85–100 小时；主线 20 章 + 序章 + 终章 |
| 队伍规模 | 8 名可操作角色，前线 4 人 + 后备 4 人，战中可换人 |
| 叙事结构 | 前半线性 → 中点世界崩坏 → 后半开放重组 → 巡礼收束 → 多结局 |
| 目标受众 | 16+，偏好厚重世界观、宗教政治、群像与养成深度的传统 JRPG 用户 |
| 关键词 | 使徒牌／信仰源泉／龙脉／异端裁决／紫曜花／四方裁定 |

### 1.3 三条设计原则

- **一切系统都由世界观长出来，不额外发明**。MP 就是「核砝」，回复道具就是「温泉」，纯度单位就是「摄符」，技能树里程碑就是设定里已有的 24 级【红蛇】到 120 级【众神降临】，羁绊系统就是「使徒牌」。玩家学的每一套规则，剧情里都有对应解释。
- **专名分层投放**。设定集有 200+ 专名，前十小时只出现核心层约 20 个；次级层通过「典籍图鉴／圣物图鉴／魔物图鉴」在探索中被动吸收；背景层只存在于可选阅读物。**不做开场名词轰炸**。
- **让人物替玩家提问**。设定集里最难消化的是两大教廷的教义分歧与异端裁决所的四套机构。不要靠旁白讲，让一个「黑皇帝」撒克逊（主张教权与王权分离）和一个守夜者（以黑暗对付黑暗）在队伍里吵。

## 2. 模板参照：向经典 JRPG 借什么

「以经典为模板」指的是**借结构、节奏与系统抽象，不借设定与角色**。下表是本项目的取舍依据。

| 参照作品 | 借用的结构 | 在《天神下凡》中的落地 |
| --- | --- | --- |
| 《最终幻想 VI》 | 群像叙事；反派在中点获胜并改写世界；后半段自由回收散落同伴 | 第二部末「第 43 届牌阵强行颁布」＝世界崩坏；第三部以找回被「除名」的同伴为驱动 |
| 《最终幻想 V》／《FFT》／《勇气默示录》 | Job System：主职业 + 副职业、跨职业技能继承 | 九大主职业 × 八大信仰源泉双轴养成，见 7.2 |
| 《时空之轮》 | 多时代因果，同一地点在不同年代呈现不同面貌 | 801 年（54 张特例牌）／821 年（现行牌）／841 年（本篇）三届牌阵互为伏笔 |
| 《女神异闻录》／《火焰纹章》 | 社群／支援等级 → 直接产出数值与合体技 | 「牌缘」系统：每结识或审判一位关键人物获得一张使徒牌，见 7.4 |
| 《勇者斗恶龙》 | 章节式单元剧，每到一个聚落解决一个独立事件 | 第一部每国一桩「异端裁决事件」，单章可独立成立，降低世界观门槛 |
| 《最终幻想 X》 | 朝圣式线性动线；终局推翻玩家一路相信的信仰前提 | 四方裁定巡礼作骨架；终局揭示「神由人造」 |
| 《八方旅人》 | 八位角色各有独立短章再合流；2D-HD 表现 | 八名同伴各配 20–30 分钟入队短章，合流点在第二部 |
| 《异度装甲》／《FF XII》 | 宗教机构、帝国政治、哲学母题、成人化叙事 | 两大教廷的「教皇永无谬论」之争、异端裁决所特权、五国博弈 |
| 《最终幻想 VII／VIII》 | 魔石／Junction 式「可装配的成长」 | 使徒牌可直接装配到角色，改变属性与可用奥义 |

### 2.1 三段式骨架（ classic JRPG 的呼吸节奏）

1. **第一部·受限的世界（约 12 小时）**：线性、每章一地一案、队伍逐人加入。玩家被「通缉异端」身份推着走，自由度低但信息密度高。
2. **第二部·打开的世界（约 20 小时）**：取得卡妙船队与传输阵后，大陆与四方圣地全开放；支线、图鉴、职业修炼、牌缘收集全面铺开。**中点在此处崩坏**。
3. **第三部·重组的世界（约 15 小时） + 终章（约 8 小时）**：崩坏后地图变化、同伴散落，逐个找回；真相回收；最终抉择与多结局。

### 2.2 合规边界（重要）

设定集中「奥古斯丁」「罗桐柴尔德」「史诗大陆」「白蔷薇皇朝」「卡妙女皇」「梵特兰蒂冈／拜占奥教廷」「使徒牌」等专名，与既有中文网络文学的专有设定高度重合；设定集自身也带有明显的摘录、OCR 与笔记痕迹（如「大6」「1o」「2o」「6续」「着称」）。

- 若本项目为**同人／非商用**：可直接沿用，但仍建议统一校订错字。
- 若计划**商业发行**：必须在 v0.2 做一次「原创化改造」——保留结构（牌阵、两教廷、信仰源泉、龙脉闭环），替换人名、国名、教廷名与专属文本，并重写神学底层。这是本大纲第 3 章要重构神学的原因之一：**结构可留，表述必须原创**。请尽早确认项目性质。

## 3. 把「天神下凡」立起来：核心概念补全

这是本次补全最重要的一章。设定集里「神」是散落的：上帝、战神、森林女神、伽马皇帝与皇后、桃乐丝女皇、奥林匹亚十二副神、midgod、七宗罪君王、撒旦七化身、上古娲族图腾……彼此没有层级关系。补全方案是把它们统一进一套**可以解释所有既有设定的神学物理学**。

### 3.1 座席（Thrones）

大陆上被称作「神」的存在，本质是十二个**位格化的世界法则**，合称「十二座席」，对应设定中「奥林匹亚山巅十二副神祗」。七宗罪君王、战神、森林女神、伽马皇帝／皇后等，都是座席在不同时代、不同族群口中的别名或堕落态。座席不具人格，只会把「权能」投射到人间。

### 3.2 使徒牌不是排行榜，是契约凭证

设定集写明：使徒牌共 55 张 = 四花色各 13 张（52）+ 黑皇帝、白皇帝、皇后（3）；由玛雅神庙、太阳神祭坛、黄金岛、拜占奥教廷**四方裁定**后方可颁行；二十年一换。

补全解释：

- 52 张花色牌 = 十二座席在人间选定的「器」，即势力、骑士团、神学院与巅峰人物。红心主战争、黑桃主智慧、梅花主和平与女性、方块主权力（完全沿用设定第 345 行）。
- 黑皇帝 = 座席的「否决票」，永远授予被正统判定为异端者；白皇帝 = 座席的「解释权」，千年不变地属于拜占奥教廷教皇。
- **【皇后】是第十三席，一个从未被承认的空席**。空白不是「人选空缺」这么简单——它代表一条规则：**神若要真正降临人间，必须借一具凡人之身，且这具身体会随权能注入而被逐渐覆写人格**。十二座席拒绝过一次，于是这张牌自 801 年起空了四十年。
- 所谓「下凡／Advent」，就是**座席把权能投放到某个人身上，使其从「有牌之人」变成「御座者」**。标题《天神下凡》指向的不是神明降临的壮观场面，而是「谁被推上那张空椅子，以及他还是不是他自己」。

### 3.3 801 年的 54 张特例牌（现成的麦高芬）

设定集给了一个极其漂亮的伏笔：某届原始牌阵只有 54 张，因为【黑皇帝】与【皇后】两张人头牌**重叠**；玛雅神庙与拜占奥教廷驳回，四套被封存、销毁或遗失，其中一套经庞培家族、尼禄之手，四十年前到了奥古斯丁手里；而圣阿尔忒弥斯当年赠予他的那张人头牌，绘图与材质与迷宫盒中的版本一模一样。

大纲将其固定为：**神圣历 801 年，第 41 届改订**。那一年牌阵判定「最大的异端，就是唯一有资格坐上空席的人」——即黑皇帝撒克逊的精神先辈（「剃刀神学家」一脉）与皇后重叠。四方否决后，教廷销毁了记录。841 年第 43 届改订在即，同样的重叠再次出现，而这一次，**被印上牌的人与主角有关**。

这条线一次性解决了：主角为什么被卷入、父亲为什么必须死、圣阿尔忒弥斯为什么三次现身、以及终局为什么必须做出选择。

### 3.4 把散落的力量设定串成一个闭环

设定集已有「核砝」「龙脉」「魔法级数」「信仰源泉」「传输阵／黄金双十字切割点」「温泉」「摄符」，但彼此孤立。补全为一条链：

> **座席**（权能源头）→ **龙脉**（权能在大陆上的导线，圣梅根为最大一条）→ **核砝**（人体接口，纯度决定可承载的上限）→ **信仰源泉**（提高带宽的「协议」，主修与辅修决定调取哪一类权能）→ **魔法级数**（单次调取的输出强度，24 级【红蛇】…120 级【众神降临】）→ **温泉／摄符**（接口耗竭后的补充资源与纯度单位）。

由此，设定里几个原本突兀的条目全部获得解释：

- 防御结界「稀释周围元素产生魔法真空」＝暂时切断局部导线，代价是自己也不能反攻（设定第 85 行，天然的战术取舍）。
- 「暗金序列元素能破解实体魔法的元素构成、伤口难愈」＝直接干扰导线协议，做成破防／禁疗属性。
- 「《空间契约坐标》：强大魔法师可在经纬假想线的神秘交叉点传输」＝传送点的世界观依据，也解释了交通解锁节奏。
- 「玛雅神庙每五年选十名贤者，考核官是沉睡于龙脉的巨龙」＝龙是导线的守卫，不是普通怪物。这直接给了一个中期 Boss 与一套职业试炼玩法。
- 「信仰源泉八大主系统」「家族忠诚与爱情容易剧烈冲突」＝现成的养成冲突规则，见 7.3。

### 3.5 千年沉默，与两大教廷为什么分裂

设定集写明：拜占奥教廷是正统，主张「教皇永无谬论、永远正确」；脱胎于它的梵特兰蒂冈教廷效忠帝国皇帝，且**拒绝**这一观点，其「牧」地位仅稍高于红衣大主教，甚至要服从十人红衣会议。

补全为对同一件事的两种解释：

- 拜占奥教廷：最后一次公认的「下凡」在神圣历 741 年，此后座席沉默。教皇宣称「神已说完一切，由我代述」，于是「永无谬论」是**填补沉默的政治装置**。
- 梵特兰蒂冈教廷：认为座席仍在说话，只是牌阵被人篡改；因此牧不能永无谬论，必须受红衣会议制衡。它效忠皇帝，本质是借世俗权力对抗教皇对解释权的垄断。

于是「异端」的定义也清晰了：**异端不是不信神，而是不承认现任解释者**。撒克逊主张教权与王权分离被判异端、多明戈隐修会因质疑教宗无误权柄沦为异端、白蔷薇因资助多明戈被四国监管——设定集里这三条原本分散的政治线，全部指向同一个矛盾。

### 3.6 终局反转（JRPG 的核心情感装置）

四方裁定这一机制本身就是答案：**牌由四方势力共同确认后才颁行，所以所谓「神意」，是四个权力机构协商出来的产物**。主角的父亲、帝国大术士一脉，正是因为查到了 801 年特例牌的原始记录，才被以叛国罪清除；歌谢尔女王亲自审判他，教务院与审判团需要这份判决来保住 841 年的改订。

终局选择因此不是「打倒魔王」，而是：**当全世界都相信神通过牌阵说话，你要不要坐上那张空椅子，成为下一句神谕**。呼应设定第 352 行那句看似闲笔的话——「历史上最著名的帕雅战棋博弈中，很多场最终都是一枚可有可无的平民棋子致胜」。

## 4. 世界观

### 4.1 时间轴（神圣历）

| 年份 | 事件 | 在游戏中的位置 |
| --- | --- | --- |
| 741 | 最后一次被公认的「下凡」；此后座席沉默，白皇帝确立 | 背景／典籍 |
| 781 | 第 40 届使徒牌 | 背景 |

| 812 | 西默农战役与《西默农条约》，白蔷薇被四国监管；多明戈隐修会沦为异端 | 序章舞台 |
| 821 | 第 42 届（现行牌）：金雀花黑桃 A、撒克逊黑皇帝、卡妙女皇方块 Q、朱毗特大帝方块 J、白蔷薇皇帝被除名 | 游戏内「当代常识」 |

| 841 | **本篇开篇**：第 43 届改订之年，四方裁定重启 | 主线 |
| 841+ | 牌阵强行颁布，龙脉逆流（中点崩坏） | 第二部末 |

> 「这以后四十年两届扑克牌，【皇后】就一直是空白」——801 → 821 → 841，正好两届，与设定集完全对齐。设定集里 119／78／49 年前圣阿尔忒弥斯三次现身的记载，对应 722／763／792 年，跨越一个世纪，是她并非普通人类的明证（她是最早一任「御座者候选」，被时间遗忘的人）。

### 4.3 势力与各自对「下凡」的立场

| --- | --- | --- |

| 梵特兰蒂冈教廷（牧） | 效忠皇帝、拒绝永无谬论、两院六部、十人红衣会议 | 要**阻止**改订，或让空席继续空着 |

**关键设计**：没有纯粹的「魔王」。每一方都有可被理解的理由，且都会在不同章节短暂成为玩家的临时盟友——这是《FF XII》《异度装甲》式的政治质感，也避免设定集里「异端 = 坏人」的扁平化。

### 4.4 力量体系：双轨制、九职业、八源泉

设定集里三套等级看似冲突：魔法师用宿根草／紫百合／剑蝶菊徽章分低中高阶、每阶三位；骑士与剑士都是九级、高中初三阶 × 上中下三位；魔法却另有 24／36／42／50／52／60／120 的「级数」。补全为**双轨**：

- **人物位阶（谁在施法）**：全职业统一为「九阶 × 三位」（初／中／上阶 各分 上／中／下位），第十阶起为**冠位**——魔法师称大魔法师／贤者，骑士称银盾→大宫廷→圣棺骑士，剑士称剑师→大剑师→剑圣，傀儡师称傀儡亲王／傀儡帝王。原设定所有徽章、勋章、称号原样保留，只是挂到同一根刻度上。
- **术式级数（施出多大的法）**：24【红蛇】、36【巨鲸】、42【双头蛇娜迦】、50【大地颤鸣】、52【君王恩宠】、60【瀑布】、120+【众神降临】。这是**技能强度**，与人物位阶无关。「魔法师每升一级可用法术级数提高 5 级，但边际递减，20 级皇家协会魔法师驾驭 80 级魔法已是极限」（设定第 118 行）直接做成数值曲线。120 级【众神降临】设为终盘唯一可习得的禁咒，与标题呼应。

**九大主职业**（设定【职业类】列 7 种，帕雅战棋章节明确「包揽 9 种全部主职业角色」，据此补齐 2 种）：

| 编号 | 职业 | 定位 | 设定依据 |
| --- | --- | --- | --- |
| 1 | 魔法师 | 元素输出／核砝消耗 | 核砝、魔法阵、元素序列 |
| 2 | 奥术师 | 治疗、封印、增益 | 绽放、十字架、治疗图腾、凝滞奥术；圣哲罗姆使其脱离「魔法婢女」 |
| 3 | 骑士 | 前排坦／信仰驱动 | 九阶、信仰源泉、圣棺骑士 |
| 4 | 剑士 | 物理爆发 | 九阶、剑圣刻名莫卧尔石 |
| 5 | 修士 | 白／黑神品，辅助与审判 | 黑神品十品次、白神品七品次 |
| 6 | 赏金猎人 | 捕获、素材、委托 | 两大宗旨 |
| 7 | 刺客 | 先制、异常状态 | 职业列表 |
| 8 | 萨满（补） | 灵魂、召唤、异端法术 | 萨满法师「灵魂领域遥遥领先」、midgod、缪斯大陆 |
| 9 | 傀儡师（补） | 捕获魔物、召唤傀儡 | 傀儡七级爵位、灵魂坍缩、黄金傀儡需进食 |

黑魔法师、亡灵法师、红伽马术士、占星术士、祭司长、玛雅光明祭祀等，不做独立主职业，而是**上级职业／禁断职业**，通过主线条件或隐藏试炼解锁——这正好承接设定里「黑炼金术被判异端」的叙事：用禁断职业会被守夜者追捕，形成玩法与剧情的互相制造麻烦。

**八大信仰源泉**（把设定中散落的名称收束为 8 个主系统，子项保留原设定）：

| 主系统 | 主要子项 | 战斗倾向 |
| --- | --- | --- |

| 忠诚 | 家族 | 护卫、代伤、队伍增益 |
| 爱情 | — | 成长慢但上限最高，「紫罗兰骑士」一脉，靠近圣棺骑士 |
| 虔诚 | 教徒／教父／圣徒 | 圣属性、对黑暗种族特攻；圣徒需一生远离七宗罪（约束型） |

设定第 168 行「家族忠诚与爱情太容易剧烈冲突，一旦扈从所爱偏离家族，可能直接毁掉主信仰」直接实现为**信仰悖论机制**：冲突组合锁掉部分被动，但解锁专属双人合体奥义。第 166 行赫拉在「正义与牺牲两大信仰崩塌后」改主修【忠诚·家族】，是现成的角色成长事件，可做成一次可玩的「改宗」演出。

### 4.5 术语校订（v0.2 执行）

设定集为笔记摘录，存在系统性的 OCR 讹误，正式文案需统一：大6→大陆、1o/2o/5o/6o→10/20/50/60、6续→陆续、着称→著称、唿啸→呼啸、交-配→交配、一摸一样→一模一样、行（颁行）、《教诲》卷数（公开 8 卷，尚有 5 卷 → 全 13 卷）、教延→教廷、bsp; 等残留标记。另将「史诗大陆／缪斯大陆／蛮荒大陆」三者的关系明确为：**史诗大陆（人类文明）＋ 缪斯大陆（即蛮荒大陆，异族与萨满）＋ 不列颠岛链（新大陆）**，设定集中「缪斯大6（蛮荒大6）」已给出等号，需在文档中固定，避免玩家困惑。

## 5. 角色与队伍

### 5.1 队伍设计原则

八人队伍按经典 JRPG 的「阵营错位」配置：每一名同伴都来自一个与主角立场冲突的势力，且各自带着一条**能与主线母题互文**的个人命题。八人各有 20–30 分钟独立入队短章（八方旅人式），合流点在第二部。

**离队与回归**：第二部末牌阵重排，设定中「除名」机制获得玩法含义——部分同伴的牌被抹去，角色从队伍与图鉴中一同消失，物理／魔法能力被封。第三部的核心动作就是**把他们一个个找回来**，这是《FF VI》后半段最有效的情感结构。

### 5.3 主角动机线（设定集完全缺失，此处补全）

- **起点**：841 年，父亲被绞死第十年。主角在白蔷薇靠替人做核砝鉴定与低阶奥术活计为生，刻意不碰魔法协会（设定：魔法被工会与研究院垄断，泄密可判十年以上，甚至终身监禁）。
- **引爆**：第 43 届改订风声传来，教廷以「清查 801 年特例牌残党」为名在白蔷薇抓人；主角被认出罗桐柴尔德血统，遭「黑暗使徒」追捕。他怀里那张圣阿尔忒弥斯赠予的人头牌，第一次被人认出是【皇后】。
- **中段转向**：查到父亲并非因政治倾轧而死，而是因为他在皇家魔法研究院接触到了 801 年四方裁定的原始记录——牌阵是人写的。
- **终点**：主角必须决定要不要用自己这张「空白牌」去坐上第 13 席，以换取撤销所有被「除名」者的判决。
- **贯穿意象**：家族肖像画遗言「敌人一天不死，紫曜花永不凋零」与迦卡妙的称号「黑色紫曜花」形成双关，在终章收束。

### 6.3 中点崩坏要达成的三件事

1. **玩法上**：地图重制、队伍解散、已收集的使徒牌部分失效，玩家被迫用低配队伍重新探索熟悉地区（《FF VI》后半段）。
2. **叙事上**：反派赢了，而且是「合法地」赢了——四方裁定程序完整，没有人作弊。
3. **主题上**：把「被排名者」变成「被除名者」。设定集里白蔷薇皇帝被使徒牌遗弃沦为笑谈、卡妙被大陆遗忘百年、半兽人被称为「瘟疫传播者」——这些原本分散的「被遗忘者」在中点之后成为主角的同类，第三部的情感重心由此成立。

### 6.4 结局设计

| 结局 | 条件 | 结果 |
| --- | --- | --- |
| A·受冠 | 主线直通 | 主角坐上第 13 席，牌阵恢复、除名者复归，但人格被逐渐覆写；结尾是圣阿尔忒弥斯替他合上眼睛 |
| B·焚牌 | 未集齐 13 卷，选择毁掉牌阵 | 神谕体系崩溃，两大教廷失去合法性，大陆陷入长期混战；人自由了，也失去了秩序 |
| C·留白 | 集齐 13 卷 + 全牌缘 | 公开「牌由人写」的真相，让【皇后】继续空白；四方失去神权但保留行政，最克制的结局 |
| D·逆位 | 撒克逊／卡妙女皇好感线达标 | 把空席让给他人，主角替其承受覆写；政治格局重组 |
| E·第 56 张（真结局） | C 条件 + 帕雅战棋「平民棋子」支线全通 | 让所有未被排名者一同入阵，牌阵由 55 张变为 56 张，神座被所有人分担——「天神下凡」的最终答案是：下凡的不是一位神，是所有没被写在牌上的人 |

E 是对设定第 352 行那枚「最没用却常常致胜的平民棋子」的回响，也是本作区别于模板作品的原创落点。

## 7. 系统框架（大纲级）

### 7.1 战斗

ATB 蓄条 + 前后排站位；四人出战、四人后备，战中换人消耗半条 ATB。保留设定中「防御结界稀释元素造成魔法真空、自身也难反攻」作为高风险高回报的战术按钮。Boss 战引入「裁定」机制：部分 Boss 拥有使徒牌，可临时改写场地规则（如「本场禁止元素魔法」「本场【虔诚】系失效」），迫使玩家换职业与换牌，而不是堆数值。

### 7.2 职业系统（Job）

九大主职业 + 禁断上级职业；角色可设「主职业 + 副职业」，副职业技能按熟练度继承（FF5／FFT 式）。职业经验与人物位阶分离，允许低等级高职业熟练的 Build。上级职业解锁绑定主线事件与圣地试炼，例如玛雅神庙巨龙考核通过才可转「贤者」。使用禁断职业会在城镇触发守夜者追捕事件——系统与剧情互相制造麻烦。

### 7.3 信仰盘（Faith Grid）

每名角色可设 1 个主源泉 + 1 个辅源泉（八大主系统 × 子项）。主源泉决定成长曲线与被动池，辅源泉决定合体奥义与队伍连携。冲突组合（如【忠诚·家族】×【爱情】、【荣耀·正义】×【战争·牺牲】）触发「信仰悖论」：锁定部分被动，但解锁专属双人技。改宗为一次性剧情事件，赫拉的改宗是全作第一次示范。

### 7.4 使徒牌「牌缘」

- **获取**：结识、击败、审判、赦免关键人物，或完成其个人支线，即可获得对应牌；共 55 张对应牌位 + 若干事件牌。
- **装配**：每名角色 3 个牌槽，四花色分别提供物理／魔法／辅助／统率四类增益；异例三牌（黑皇帝、白皇帝、皇后）为剧情限定，效果极强且附带代价。
- **牌缘等级**：与角色的共同战斗、对话选择、赠礼提升牌缘，解锁合体奥义与角色短章（Persona 式社群）。
- **牌阵重排**：821 年现行牌 → 841 年新牌，剧情会自动重排玩家已持有的部分牌；玩家可通过「抗命」（拒绝新牌）改变结局分支。这是把世界观直接做成系统的关键一笔。
- **被除名**：中点崩坏后部分牌从图鉴消失，找回同伴即找回牌。

### 7.5 成长与经济

| 设定术语 | 系统映射 |
| --- | --- |
| 核砝纯度 | 最大 MP / 术式承载上限，随位阶与装备成长 |
| 温泉（摄符为纯度单位） | 主要 MP 回复资源，可采集、炼成、交易；高纯度温泉是稀缺品 |
| 魔法级数 24–120 | 技能树里程碑，【众神降临】为终盘禁咒 |
| 暗金序列元素 | 破防／禁疗属性，专克实体魔法与治疗图腾 |
| 徽章／勋章 | 位阶认证与被动装备（宿根草、紫百合、剑蝶菊、巴思勋章、神鸦圆徽等） |
| 魔法阵（线型／粉末／实体） | 法术形态分类，影响吟唱时间、范围与可否被打断 |
| 圣物／铠甲／武器 | 装备主条目，设定集已给出「所罗门钥匙圣铠」「叶斐尔圣母」「奥丁大铠」「陨落十字」等成体系专名 |
| 矿物评级（神圣／史诗／咏叹…） | 强化素材稀有度，直接沿用设定第 306 行的评级序列 |

经济循环：委托（赏金猎人）→ 金币与素材 → 核砝鉴定／温泉炼成／装备强化 → 挑战更高术式 → 解锁新区域。设定中「魔法被两大机构垄断、教科书严禁印刷、泄密重罪」解释了为什么玩家不能随便在商店买高阶法术，必须用探索与牌缘获取——稀缺性有叙事依据。

### 7.6 支线、小游戏与收集

- **帕雅战棋**：可全程游玩的棋盘小游戏（设定中「规则繁琐、角色众多、两百余枚象牙棋子」），九个主职业棋子 + 异端棋子 + 平民棋子。设一条贯穿全篇的 NPC 棋手线，终盘「平民棋子」解法直通真结局。
- **典籍图鉴**：设定集列出约 40 部典籍（《教诲》《禁区》《空间契约坐标》《魔法七大基石定律》等）。其中《教诲》13 卷为主线级收集，其余提供世界观与被动加成。
- **圣物／魔物／坐骑图鉴**：设定集已提供上百条现成条目（六眼黄金猴、塔尔塔洛斯地狱犬、紫珊瑚黑蟒、娲龙、海泽纯血马等），足够支撑全收集而不需新造名词。
- **魔物捕获**：傀儡师职业「捕获黑暗深渊生物、灵魂坍缩成傀儡，且傀儡需要进食」是现成的收集养成玩法，可与图鉴合并。

### 7.7 探索与节奏控制

交通工具六级解锁（见 4.2）；每解锁一级同步开放：新地图、新支线、新图鉴页、新职业试炼。第一部严格限制跨区移动，第二部完全开放，第三部以「熟悉地点的崩坏版本」回收探索欲——这是控制 50 小时体量不注水的标准做法。

## 8. 主题、意象与音画方向

- **母题**：谁有资格代神说话？被排名者与被除名者，谁才是世界的多数？
- **核心意象**：紫曜花（家族遗言／迦卡妙的称号）、空白的牌（缺席比在场更有力量）、钟声（亡灵钟楼／「图浮宫钟声」猎熊犬／凯撒门的棺材）、玫瑰（红玫瑰的恶龙、黑玫瑰骑士团、白蔷薇皇朝）。
- **叙事语气**：设定集最好的气质是「庄严与滑稽并置」——驱逐黑龙丹东的真相只是想要一小截龙骸做眼镜、帝国第六骑士其实邋遢、帝国骄阳拿破仑是私人神父的唯一学生。务必保留这种反差，它是本作避免沦为沉重说教的关键。
- **音乐**：以一段「紫曜花」主题动机贯穿全篇，四花色各配一套变奏（红心＝铜管与军鼓，黑桃＝钢琴独奏，梅花＝弦乐与童声，方块＝管风琴）；教廷场景用拉丁圣咏，缪斯大陆用萨满人声与打击乐；终章主题曲回收主题动机并去掉所有神性配器，只留独奏。
- **美术**：2D-HD；四大花色作为四套主色调分区；使徒牌采用可翻面的实体卡牌美术，玩家在菜单里看到的是一副真正会随剧情变旧的牌。

## 10. 后续路线与待拍板

**版本路线**：v0.1 大纲（本稿）→ v0.2 世界观圣经 + 专名校订／原创化 → v0.3 八名角色与九职业详细设定 → v0.4 全 20 章剧本梗概与对话基调 → v0.5 系统数值与战斗原型 → 可玩原型。

**需要尽早拍板的五项**：

1. **项目性质**：同人／非商用，还是商业发行？决定是否需要整体原创化改名（见 2.2）。这一项会影响后续所有文案，优先级最高。
2. **终局反转是否采用**：本大纲把「神由人造、牌由人写」设为全作核心答案，并让主角面临「是否坐上神座」。若希望更传统的「神明确实降临、打倒伪神」路线，第 3、6 章需重写。
3. **战斗制式**：ATB + 站位（推荐，兼顾演出与节奏）还是 CTB 战棋（更贴合帕雅战棋与 FFT 味，但会显著改变关卡与地图设计）。
4. **美术与体量**：2D-HD／8 人队伍／50 小时主线是相互匹配的组合；若资源受限，可先砍到 5 人队伍 + 30 小时，第一部与第二部前段可完整保留。
5. **专名保留清单**：哪些名字必须留（作者情感上不舍得改），哪些可以让步。建议至少锁定「使徒牌」「紫曜花」「帕雅战棋」「四方裁定」四个为不可替换的核心符号。
